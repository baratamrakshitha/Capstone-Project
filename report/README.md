# Satellite Telemetry Anomaly Detection Using Machine Learning
## Capstone Project Demonstration & Academic Report Suite

This directory contains the academic project report suite and demonstration notebook for the B.Tech Capstone Project based on the European Space Agency (ESA) OPS-SAT-AD benchmark:
*"The OPS-SAT benchmark for detecting anomalies in satellite telemetry"* (Bogdan Ruszczak et al., 2024, arXiv:2407.04730v1).

### Quick Start for Google Colab

1. Open [Google Colab](https://colab.research.google.com).
2. Upload `Satellite_Telemetry_Anomaly_Detection_Demo.ipynb`.
3. In Colab's Files panel (📁), upload `data/dataset.csv` (and optionally `data/segments.csv`).
4. Select **Runtime > Run all** (or press `Ctrl + F9`).
5. For complete presentation talking points and examiner guidelines, refer to [`COLAB_RUN_GUIDE.md`](COLAB_RUN_GUIDE.md).
